# Dayana Travel MVP

MVP сайта самостоятельного подбора туров для Dayana Travel.

## Что работает

- поиск по городу вылета, стране, дате, длительности и бюджету;
- клиентская фильтрация и сортировка каталога;
- расчёт ориентировочной стоимости на выбранное количество туристов;
- карточки туров и выбор конкретного варианта;
- форма отправки тура менеджеру на проверку;
- избранное с сохранением в localStorage;
- русский и английский языки;
- светлая и тёмная темы;
- адаптивная мобильная версия.

## Запуск

```bash
npm install
npm run dev
```

## Важно перед публикацией

Сейчас каталог и цены демонстрационные и находятся в `src/App.tsx` в массиве `TOURS`.
Для реальных цен, наличия и бронирования необходимо подключить API туроператора или агрегатора.
Также замените значения в `CONTACTS` на реальные контакты Dayana Travel.
